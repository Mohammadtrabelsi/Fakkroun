# فكّرون (Fakkroun)

**Think, Answer, Learn, Win!** فكّرون منصة أسئلة وأجوبة متعددة اللغات (العربية والفرنسية والإنجليزية) تعمل في الوقت الفعلي، وتركّز على الاقتصاد الأخضر والاقتصاد الأزرق والتوعية البيئية. يلتحق اللاعبون بالمسابقات المباشرة برمز غرفة أو برابط دعوة، دون الحاجة إلى حساب.

تُبنى فكّرون على حزمة **MajidaStarter** (Laravel 13 و Livewire 4). مرجع الحزمة موجود في [`starter-kit.md`](starter-kit.md).

> لغات أخرى: [English](../en/README.md) · [Français](../fr/README.md)

## الحالة

- **نسخة أولى قابلة للتشغيل (MVP)**: بنك الأسئلة والإشراف والمشاركات المجتمعية والغرف متعددة اللاعبين مباشرةً والتسجيل والنتائج والإعلانات والتحليلات منفّذة.
- **الاختبارات**: نجحت مجموعة الاختبارات محلياً بتاريخ 11/11/2026 (664 اختباراً). ما زال PHPStan يبلّغ عن أخطاء.
- **التكامل المستمر (CI)**: لم تبدأ GitHub Actions أي مهمة وقت تسجيل هذه الحالة. تحقّق من آخر تشغيل قبل الاعتماد عليه. انظر [`../fakkroun/03-next-step-run-ci.md`](../fakkroun/03-next-step-run-ci.md).
- **خارطة الطريق وتقارير المراحل**: [`../fakkroun/`](../fakkroun)، بدءاً من [`02-mvp.md`](../fakkroun/02-mvp.md) و[`15-roadmap.md`](../fakkroun/15-roadmap.md).

## الميزات

| المجال | ما الذي يفعله |
| --- | --- |
| **المسابقات المباشرة** | ينشئ المضيف غرفة (المواضيع، وعدد الأسئلة، والثواني لكل سؤال، والصعوبة، واللغة، وأقصى عدد للاعبين). تحصل كل غرفة على رمز من 6 خانات ورابط دعوة ورمز QR. تتيح قاعة الانتظار النسخ وWeb Share وWhatsApp. يحدّد الخادم كل المهل ويحسب النقاط؛ ولا يرسل العميل سوى الاختيار. |
| **اللعب كضيف** | يستطيع أي شخص الانضمام إلى غرفة برمز أو رابط دعوة واسم مستعار. إنشاء غرفة يتطلب حساباً. |
| **قاعدة الإجابات المتطابقة** | عندما يعطي عدد كافٍ من اللاعبين الإجابة نفسها، لا تُحتسب نقاط لأيٍّ من تلك الإجابات. يُضبط الحد في إعدادات الإدارة. |
| **النقاط والنتائج** | نقاط حسب الصعوبة مع مكافأة للسرعة. لوحة متصدرين مباشرة، وترتيب نهائي، وإحصاءات لكل لاعب. سجل المسابقات والإنجازات ولوحة متصدرين عامة (أسبوعية وإجمالية). |
| **بنك الأسئلة** | أسئلة من أربعة خيارات، مع ترجمة لكل لغة تُعتمد على حدة. دورة الحياة: مسودة، ثم قيد الانتظار، ثم قيد المراجعة، ثم معتمد، ثم منشور. سجل للمراجعات، واكتشاف للتكرار التام والتقريبي، واستيراد وتصدير (CSV وXLSX وJSON). |
| **الإشراف** | قائمة انتظار للأسئلة والترجمات وبلاغات اللاعبين. يقتصر المشرفون على فئاتهم. كل قرار مسجّل. |
| **المجتمع** | يقترح اللاعبون أسئلة ويتابعون حالتها. يُبلَّغ الكتّاب بالقرار. |
| **صياغة بمساعدة الذكاء الاصطناعي** | يستطيع الطاقم توليد مسودات أسئلة عبر واجهة Anthropic. تبدأ المسودات دائماً كمسودات قيد المراجعة. تُخفى الميزة عند غياب مفتاح API. |
| **الإعلانات والفوترة** | لوحة للمعلنين وحملات وشركاء وباقات وتتبّع للنقرات الإعلانية. تمر المدفوعات عبر مزوّد قابل للاستبدال، والمزوّد الافتراضي هو `cash`. |
| **التحليلات** | لوحات إدارة للمسابقات واللاعبين والإجابات ونسبة الصحيح وزمن الاستجابة والمواضيع واللغات وصحة بنك الأسئلة والإعلانات. |
| **أساس الحزمة** | تسجيل الدخول مع التحقق الثنائي، والأدوار والصلاحيات، وسجل النشاط، والإشعارات، والنسخ الاحتياطي، وفحوص الصحة، والمدونة، وRSS، وخريطة الموقع، وواجهة REST، والسمات الفاتحة والداكنة، والعربية والفرنسية والإنجليزية مع اتجاه من اليمين إلى اليسار. انظر [`starter-kit.md`](starter-kit.md). |

يتوفر تسجيل لمسابقة مباشرة في [`../fakkroun/demo/fakkroun-demo.mp4`](../fakkroun/demo/fakkroun-demo.mp4) (دقيقة و40 ثانية، المضيف على حاسوب محمول واثنان من الضيوف على هواتف).

## المتطلبات

- PHP 8.4 أو أحدث، مع الإضافات `mbstring` و`pdo` و`intl` و`bcmath` (تستخدم CI أيضاً `pdo_sqlite` و`sqlite3`)
- Composer
- Node.js 20 أو أحدث، وnpm

## البدء السريع

```bash
# 1. تثبيت الاعتماديات، وإنشاء ملف .env، وتوليد مفتاح التطبيق، وتشغيل الترحيلات، وبناء الأصول.
#    اضبط قاعدة البيانات في .env أولاً، لأن الترحيلات تعمل هنا.
composer setup

# 2. ملء قاعدة البيانات. اختر أحد الخيارين:
php artisan db:seed --class=ConfigDatabaseSeeder  # الأدوار والصلاحيات والمدير و14 فئة وحزم المعلنين
php artisan db:seed                               # ما سبق، إضافة إلى مستخدمين تجريبيين وأسئلة نموذجية منشورة ومسابقة تجريبية

# 3. جعل الملفات المرفوعة (صور الغلاف والشعارات) متاحة للعموم.
php artisan storage:link

# 4. تشغيل بيئة التطوير (خادم PHP، ومعالج الطوابير، ومتابعة السجلات، وVite).
composer dev
```

للتجربة باستخدام SQLite، اضبط هذا في `.env` قبل `composer setup`، ثم أنشئ الملف:

```dotenv
DB_CONNECTION=sqlite
DB_DATABASE=database/database.sqlite
```

```bash
touch database/database.sqlite
```

### تسجيل الدخول

| من | أين | الحساب |
| --- | --- | --- |
| الطاقم (المديرون والمشرفون وكتّاب الأسئلة) | `/admin/login` | `admin@fakkroun.test` / `password` |
| اللاعبون | `/login` | التسجيل على `/register`، أو `test@example.com` / `password` بعد الملء الكامل |

غيّر كلمة مرور المدير قبل النشر. اضبط `ADMIN_EMAIL` و`ADMIN_NAME` و`ADMIN_PASSWORD` في `.env`، ثم أعد تشغيل `AdminUserSeeder`. التفاصيل موجودة في [`starter-kit.md`](starter-kit.md).

### تجربة مسابقة

1. سجّل الدخول على `/admin/login`، ثم افتح **الإشراف** لمراجعة الأسئلة النموذجية.
2. في متصفح ثانٍ، أنشئ حساب لاعب أو افتح رابط دعوة الغرفة.
3. أنشئ غرفة من `/play/host` وابدأ المسابقة من قاعة الانتظار.

## الإعدادات

تجد الإعدادات الشائعة في `.env.example`. المفاتيح التالية خاصة بفكّرون.

| المتغير | القيمة الافتراضية | الغرض |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | فارغ | يفعّل صياغة الأسئلة بالذكاء الاصطناعي. بدونه تبقى شاشات الذكاء الاصطناعي مخفية. |
| `FAKKROUN_AI_MODEL` | `claude-opus-5-5` | النموذج المستخدم للصياغة. |
| `FAKKROUN_AI_EFFORT` | `medium` | مستوى الجهد في الاستدلال للصياغة. |
| `FAKKROUN_AI_BATCH_COST_CEILING` | `20.0` | أقصى تكلفة تقديرية لدفعة واحدة. |
| `FAKKROUN_PAYMENT_DRIVER` | `cash` | مزوّد الدفع خلف عقد الفوترة. |
| `FAKKROUN_TERMS_DRAFT` | `true` | يعلّم صفحة الشروط كمسودة. |
| `OWNER_PASSWORD` | عشوائي | كلمة مرور `OwnerUserSeeder` (يُشغَّل وحده). |

إعدادات الحزمة (الطوابير والنسخ الاحتياطية وفحوص الصحة وخريطة الموقع والخلاصات وPDF والحماية من الرسائل المزعجة وغيرها) مدرجة في [`starter-kit.md`](starter-kit.md).

للإنتاج، انظر [`../fakkroun/13-deployment.md`](../fakkroun/13-deployment.md) وملاحظات [`starter-kit.md`](starter-kit.md). إعداد Docker موصوف في [`../../README.docker.md`](../../README.docker.md).

## البنية

```
app/
├── Domain/                 # منطق فكّرون، مجلد لكل مجال
│   ├── Advertising/        # الحملات وعرض الإعلانات والنقرات
│   ├── Ai/                 # صياغة الأسئلة (واجهة Anthropic)
│   ├── Analytics/          # إحصاءات الإدارة
│   ├── Billing/            # الباقات والسجل المالي وعقد مزوّد الدفع
│   ├── Gameplay/           # الغرف ومحرك اللعب والنقاط وقاعدة التكرار
│   └── Questions/          # بنك الأسئلة والإشراف والمشاركات والاستيراد
├── Services/               # خدمات الحزمة، خدمة لكل نموذج
├── Http/Controllers/Api/   # المتحكمات الوحيدة: واجهة JSON
└── Models/, Policies/, Observers/, Notifications/, ...

resources/views/pages/      # مكوّنات Livewire ذات الملف الواحد: كل صفحة ويب
database/                   # الترحيلات والمصانع وبذور البيانات
routes/web.php              # مسارات الويب، مجمّعة حسب مستوى الوصول
routes/api.php              # واجهة JSON
lang/{en,fr,ar}/            # الترجمات
docs/                       # توثيق المشروع
```

- **الصفحات مكوّنات Livewire** في `resources/views/pages/`. تتحقق من المدخلات وتفحص الصلاحيات وتفوّض العمل إلى الخدمات.
- **منطق العمل يعيش في الخدمات** (`app/Services` و`app/Domain`). لا يُقرأ النموذج ولا يُكتب إلا عبر خدمته. يتحقق `tests/Feature/Architecture/ServiceLayerTest.php` من ذلك.
- **التحكم في الوصول** يعتمد على السياسات لكل نموذج وصلاحيات `spatie/laravel-permission`. تحمي مسارات الإدارة وسيط `backoffice`.
- **الترجمات** مقسّمة حسب الميزة، مع `__()` لكل نص ظاهر. يعرض `php artisan translations:sync --dry-run` المفاتيح الناقصة.

## الواجهة البرمجية (API)

تقع نقاط النهاية بصيغة JSON تحت `/api` وهي معرّفة في [`routes/api.php`](../../routes/api.php). تستخدم نقاط الإدارة بوابات الصلاحيات نفسها التي تستخدمها شاشات الويب. تتطلب إرسال الأسئلة الصلاحية `submit questions`.

- **المصادقة**: يعيد `POST /api/auth/token` رمز حامل (`Authorization: Bearer <token>`)، ويلغيه `DELETE /api/auth/token`. تسجيل الدخول بملف تعريف الارتباط للجلسة متاح عبر `POST /api/auth/login`. تُطلب رموز التحقق الثنائي عند تفعيله.
- **تحديد المعدل**: طلبات التسجيل وتسجيل الدخول وإصدار الرموز محدودة بـ6 طلبات في الدقيقة لكل بريد إلكتروني وعنوان IP.
- **الموارد**: الملف الشخصي، وإرسال الأسئلة والبلاغات عنها، والفئات، والمقالات، والمستخدمون (بما في ذلك التعليق وإعادة التفعيل)، والإعدادات.
- **الأخطاء** تُعاد دائماً بصيغة JSON. في وضع الصيانة، ترجع كل نقطة `503` إلا للمديرين.

## الاختبارات والجودة

```bash
composer test          # أو: php artisan test

composer analyse          # Larastan (PHPStan)
```

تعمل الاختبارات على قاعدة SQLite في الذاكرة (انظر `phpunit.xml`).

## المساهمة

- أنشئ الفروع من `develop`. افتح طلبات السحب نحو `develop`. لا تستهدف `main` مباشرة.
- تتبع رسائل الإيداع الصيغة `type(scope): subject`، مثل `feat(questions): add bulk import`.
- قواعد الكود والمراجعة الداخلية موجودة في [`../../CLAUDE.md`](../../CLAUDE.md).

## التكامل المستمر

يعمل `.github/workflows/ci.yml` عند كل دفع إلى `develop` و`main`، وعند كل طلب سحب. يشغّل مجموعة الاختبارات على PHP 8.4 (بعد بناء أصول الواجهة الأمامية بـNode 20)، ثم Pint وLarastan. تحقق من آخر تشغيل على GitHub، لأن الحالة أعلاه قد تكون قديمة.
