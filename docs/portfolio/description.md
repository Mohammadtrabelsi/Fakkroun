# Fakkroun: portfolio description

**Image:** `banner.png`
**One line:** A real-time, multilingual quiz platform for the green economy, the blue economy and environmental awareness.

**CV (short):** Real-time multilingual quiz platform (English, French, Arabic) on the green economy, blue economy and environmental awareness. Built with Laravel and Livewire.

**Portfolio:** Fakkroun ("Think, answer, learn, win!") turns sustainability topics into live quiz sessions. Players join in real time, answer questions and learn as they play. The interface and content are available in English, French and Arabic.

**Stack:** Laravel, Livewire, real-time updates, multilingual content
